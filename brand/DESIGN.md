# Ahmed Makkiyah brand design (from amnovahomes.com)

Use this for every client email, page or HTML deliverable, so it all matches
the website. It was taken from a Firecrawl scrape and screenshot of
amnovahomes.com (ahmedknows.com redirects there), so there's no need to
re-scrape the site.

## Colors

| Token | Hex | Use |
|---|---|---|
| navy | `#15233A` | Header bar, headings, card borders, number circles, primary buttons |
| navy-deep | `#0D1626` | Hero band and footer |
| red | `#C8102E` | Calls to action ("Call", "What's my home worth?"), alert panels |
| red-dark | `#C3161B` | Red button hover and edges |
| gold | `#ECC995` | Pill buttons on navy ("Call Ahmed"), highlights on dark backgrounds |
| bronze | `#AD9763` | Small uppercase eyebrow labels ("START HERE: BUYING OR SELLING?") |
| text | `#15233A` | Body text |
| muted | `#515C6D` | Secondary text and subtitles |
| line | `#D3CCBE` | Warm hairlines and input borders |
| line-cool | `#E1E3E6` | Dividers inside cards |
| white | `#FFFFFF` | Page and card background |

## Type

- Headings: **Fraunces** (serif). Email fallback: Georgia, "Times New Roman", serif.
  Large and light; italic for taglines ("The Ultimate Real Estate Guide, 2026").
- Body: **Public Sans**. Email fallback: Arial, Helvetica, sans-serif.
- Wordmark: **Marcellus SC** for "AHMED MAKKIYAH", with a tracked uppercase
  sub-line ("NORTHERN VIRGINIA GUIDE").
- Arabic: Tahoma, Arial.
- Eyebrows: 11px, bold, uppercase, letter-spacing 2–3px, bronze on white or
  gold on navy.

## Shapes and components

- Header: a navy bar with the AM logo on a white tile, the wordmark next to it,
  and a red pill button on the right.
- Hero: a deep-navy band with a gold eyebrow ("AM NOVA HOMES"), a large white
  Fraunces title and a white italic tagline.
- Buttons: pills (fully rounded) for main actions. Red is primary, gold with
  navy text is secondary, and navy is neutral.
- Cards: white, 2px navy border, square corners. Each has a numbered navy
  circle and a Fraunces title, with muted text under it.
- Alert or emphasis panel (like the "I'm selling" panel): a red header bar with
  white serif text, and the body below it.
- Footer: deep navy with the logo and muted text.

# Mr. Prime — the Interest Rate mascot

Higgsfield prompt pack. Original character in the "old-money banker mascot"
archetype (top hat + mustache + waistcoat). **Not** Hasbro's Monopoly mascot —
distinct face, distinct hat, distinct props, safe to use on branded content.

Character read: *cute, round, delighted — and quietly benefiting from you.*
He is the interest rate. He works for the banks and the mortgage companies. Every
time someone signs, he wins a little.

---

## 0. How to run this in Higgsfield

Order matters. Consistency comes from locking the face once and referencing it forever.

1. **Generate the FACE LOCK PLATE first** (§2.1, 3:4). Pick the one you like.
2. **Upload that image as a character / reference element** in Higgsfield, then attach
   it to every later generation. Do not re-describe him from scratch each time —
   paste the DNA block *and* attach the plate.
3. **Then** generate the character sheet (§2.2) and turnaround (§2.3).
4. **Then** the expression sheet (§3) and scenes (§4).
5. Style variants (§1): generate the *same* plate composition once per style so you
   have a matched set — B&W 3D, color 3D, B&W 2D, color 2D.

Aspect ratios: face plate `3:4` · sheets & turnarounds `16:9` · thumbnails `16:9`
· stickers `1:1` · reels/shorts `9:16`.

Every prompt = `[COMPOSITION] + [DNA BLOCK] + [STYLE MODULE] + [NEGATIVE TAIL]`.
Paste them in that order, comma-separated, one paragraph. Image models weight early
tokens heavier, so composition and identity go first, quality tail last.

## 6. NEGATIVE TAIL

Always append:
> no text, no letters, no numbers, no typography, no watermark, no logos, no branding, no
> frame borders, single subject only, exactly one person, only the character in frame, no
> other people, no duplicate figures, no extra limbs, no extra fingers, no distorted
> hands, no distorted anatomy, no props other than those described, original character
> only that does not resemble any existing board game mascot brand character or
> copyrighted property

Add for **black & white** styles:
> no colour, no colour tint, no sepia tone, no partial colour accents, strictly greyscale

Add for **3D** styles:
> no photorealistic human skin, no uncanny realism, not a real person

Add for **2D** styles:
> no 3D render, no gradients on the flats, no photographic shading

Add for **scene** prompts:
> no readable documents, no signage, no visible brand marks on any object

**Referencing mechanic that works:** pass a prior generation's **job ID** straight into
`medias` with role `image_references` — no re-upload, no URL, and it references the
original 2K render rather than a recompressed copy:

```
medias: [{ value: "<prior job id>", role: "image_references" }]
```

The response echoes it back as `reference_images: ["<job id>"]`, which is how you confirm
the reference actually attached rather than being silently dropped.

Even with a reference attached, keep restating the costume and face details in the prompt.
The reference holds the *look*; the text holds the *details*. Drop the text and the
percent-sign charm, the hat pin and the asymmetric eyebrow go first.

**Keep the seeds.** Re-running a style with its seed plus a small prompt edit gives a
controlled variation instead of a brand-new character.
